# Проект: Тестирование мобильного приложения SkillCinema 🎬

**Роль:** QA Engineer (ручное тестирование)
**Задача:** Протестировать MVP-версию Android-приложения для поиска фильмов.

## 🛠 Что делала:
* Изучила техническое задание и проверила его на логические ошибки.
* Проанализировала макеты приложения в Figma.
* Установила APK-файл на Android-эмулятор (Android Studio).
* Написала тест-кейсы для проверки интерфейса и функциональности.
* Провела тестирование экранов «Онбординг» и «Главная».
* Провела тестирование экранов: «Информация о фильме», «Поиск», «Профиль».
* Составила итоговый отчет о тестировании.

## 📊 Результаты:
* Написано и пройдено: **66 тест-кейсов**.
* Найдено: **10 багов**.
* Дымовое тестирование: 16 тест-кейсов (13 Passed, 3 Failed).
* Функциональное тестирование: 50 тест-кейсов (37 Passed, 6 Failed, 7 Blocked).
* Проверено: онбординг, главная, карточка фильма, поиск, профиль, навигация.
* Составлен итоговый отчет с рекомендациями.

## 🧰 Инструменты:
Android Studio, Figma, YouGile.
